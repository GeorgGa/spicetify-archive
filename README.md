# spicetify-archive
> Some of my Spicetify snippets and other configuration changes

## Snippets
- [vinyl-spinner](https://github.com/georgga/spicetify-archive/blob/main/vinyl-spinner.css): Makes album art spin as fast as a Vinyl record, only while a song is actually playing
    - a modification of *Spinning CD Cover Art* from the [Marketplace](https://github.com/spicetify/marketplace)

- [large-album-art-vinyl-spinner](https://github.com/georgga/spicetify-archive/blob/main/large-album-art-vinyl-spinner.css): Makes album art spin as fast as a Vinyl record, only while a song is actually playing
    - like [vinyl-spinner](https://github.com/georgga/spicetify-archive/blob/main/vinyl-spinner.css), but for the *Large-scale album art* from the [Marketplace](https://github.com/spicetify/marketplace)

- [lucid-lyrics-vinyl-spinner](https://github.com/georgga/spicetify-archive/blob/main/lucid-lyrics-vinyl-spinner.css): Makes album art spin as fast as a Vinyl record, only while a song is actually playing
    - like [vinyl-spinner](https://github.com/georgga/spicetify-archive/blob/main/vinyl-spinner.css), but for *Lucid Lyrics* from the [Marketplace](https://github.com/spicetify/marketplace)
